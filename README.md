# El Códice de los Mundos

Ruta en español, sin sinopsis ni detalles de trama. La primera vez que abras la web, *El Imperio Final* ya aparece como terminado. Los cambios se guardan en el navegador donde marcas las lecturas.

## Abrir en tu equipo

Descomprime el ZIP y abre `index.html` en tu navegador. Conserva los archivos y la carpeta `assets` juntos. Puedes usar esta opción para mantener el sitio en tu equipo.

## GitHub Pages

1. Sube a la raíz de un repositorio los archivos descomprimidos, incluida la carpeta `assets`.
2. Abre **Settings → Pages**. En **Build and deployment**, elige **Deploy from a branch**.
3. Selecciona **main** y **/ (root)**. Pulsa **Save** y abre la URL que aparece en Pages cuando termine el despliegue.

Un repositorio privado y un sitio privado son configuraciones distintas en GitHub. El acceso privado de Pages requiere una organización con GitHub Enterprise Cloud. El avance se guarda por navegador y dirección: la copia local y la versión publicada tienen historiales independientes.
